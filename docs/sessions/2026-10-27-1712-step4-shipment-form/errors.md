# Errors

## Πολύ μεγάλη εντολή shell (`ENAMETOOLONG`)
- **Τι συνέβη:** η δημιουργία του `lib/formStrings.ts` με ένα heredoc στο shell απέτυχε με `ENAMETOOLONG: name too long, uv_spawn`.
- **Γιατί:** τα γαλλικά κείμενα (~300 γραμμές) έκαναν την εντολή μεγαλύτερη από το όριο των Windows για τη γραμμή εντολών.
- **Λύση:** το κομμάτι γράφτηκε ως αρχείο και ενώθηκε με το μέρος που βγήκε αυτόματα από το Fortio.

## Αντικατάσταση κειμένου που δεν βρήκε το σημείο της
- **Τι συνέβη:** ένα script node για να προσθέσει τις νέες κατηγορίες στα `CATEGORY_ICON` δεν βρήκε το σημείο αναφοράς.
- **Γιατί:** τα αρχεία έχουν τέλη γραμμής CRLF και το σημείο αναφοράς ήταν γραμμένο με LF.
- **Λύση:** οι αλλαγές έγιναν με επεξεργασία του αρχείου αντί για script.
